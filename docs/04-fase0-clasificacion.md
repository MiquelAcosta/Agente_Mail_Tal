# 04 · Fase 0 — Clasificación de la muestra

## Objetivo

Clasificar ~300 mails reales del buzón para obtener, con datos y no sensaciones:

- Las **categorías** que existen y su volumen.
- Qué % iría a humano por cada filtro (adjunto / sin historial / sucesión).
- Qué % del resto es **automatizable** y cuántos **minutos de gestión** libera.
- El catálogo real de documentos de salida.

El resultado alimenta directamente: las reglas de negocio (doc 03), el caso de negocio
para dirección (doc 06) y la DPIA (doc 05).

## Herramienta

`docs/plantillas/Plantilla_Fase0_Clasificacion_Mails.xlsx`
(instrucciones dentro del propio Excel, hoja «Instrucciones»).

**La plantilla RELLENADA no se sube al repo** (contiene datos de clientes):
se trabaja y guarda en SharePoint. Aquí solo vive la plantilla vacía.

## Procedimiento

1. Exportar la muestra del buzón (responsable: __________).
2. Revisar/renombrar en la hoja «Listas» las categorías y los 5 documentos.
3. Repartir la clasificación entre las 3 personas del equipo.
4. Reunión corta para resolver en conjunto los marcados «Con dudas» — las conclusiones
   se apuntan y acabarán siendo reglas del prompt.
5. Volcar los resultados agregados (solo números, sin datos de clientes) en este doc
   o en un Issue, y actualizar el doc 03 con las categorías definitivas.
